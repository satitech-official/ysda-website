# Youth Sports Development Academy - YSDA

Football-focused academy website for Youth Sports Development Academy, Mhow, Indore.

## Live Website

https://ysdasports.com/

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The static website is generated in `out/` and deployed automatically to GitHub Pages whenever `main` is updated.
