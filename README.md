## About the Project

This website presents YSDA as a professional youth-sports ecosystem offering football and multi-sports coaching, fitness development, tournaments, player-development programs and competitive exposure.

The experience has been designed to work smoothly across desktop, tablet and mobile devices with modern animations, interactive sections, responsive navigation and direct contact integrations.

## Main Features

- Premium responsive sports-academy interface
- Animated hero section with sports video background
- Football and multi-sports program presentation
- Academy vision, mission, values and objectives
- Coaches and training-program sections
- Events, achievements and success stories
- Filterable sports gallery and news content
- Testimonials, sponsors and partner sections
- WhatsApp, phone, email and social-media integration
- Google Maps location integration
- Smooth scrolling, animated counters and custom interactions
- SEO metadata and social-sharing configuration
- Static export optimized for GitHub Pages

## Run Locally

### Prerequisites

- Node.js 20 or newer
- npm

### Installation

```bash
git clone https://github.com/satitech-official/ysda-website.git
cd ysda-website
npm install
npm run dev
```

Open the development website at:

```text
http://localhost:3000
```

## Production Build

```bash
npm run build
```

The project uses the Next.js static-export configuration. The production files are generated inside the `out` directory.

## GitHub Pages Deployment

Deployment is handled automatically through the workflow:

```text
.github/workflows/deploy-pages.yml
```

Every push to the `main` branch automatically:

1. Installs project dependencies
2. Builds the Next.js static website
3. Uploads the generated `out` directory
4. Deploys the website to GitHub Pages
